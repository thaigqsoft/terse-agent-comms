คุยกับ AI Agent
ให้ประหยัด Token

สั่งงาน worker ด้วย contract สั้น และ follow-up เฉพาะส่วนที่เปลี่ยน

Contract template

GOAL:    one-line outcome
CTX:     facts worker can't discover
DO:      only where it'd go wrong  (optional)
RULES:   hard constraints = scope fence
DONE:    verify cmd → expected result
STOP-IF: condition → report, don't guess
REPLY:   ≤N lines, fixed fields

ก่อน → หลัง (จำนวนคำ)

Follow-up (SendMessage) ~100 → ~30 คำ
Investigation brief (read-only) ~170 → ~95 คำ
